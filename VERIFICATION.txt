Verification limits
Direct file:// opening was not tested because the cloud browser's navigation
policy did not permit that route. Windows browsers and mobile file managers
were not tested. The app intentionally uses classic inline/local scripts and
no fetch, CDN, ES-module loading, or build dependencies, to support offline
opening. Local file storage behavior still varies by browser; keep backups.
The Node DOM harness tests logic and interactions, not a browser rendering
engine. The separate Chromium checks above cover the listed visual/workflow
checks only. No performance guarantee applies to every device or maximum-size
dataset.
